# Draft evidence corpora

This directory preserves exact public-data task selections used during ranker
development. Every snapshot is unreviewed, unsealed, excluded from the npm
package, and ineligible for calibration or promotion claims.

The corresponding compact checkpoint under `benchmarks/checkpoints/` records
the hashes of large ignored materialization and review artifacts. Do not copy a
draft into the canonical corpus until the hash-bound review queue has complete
independent required-source and explicit-noise decisions and a fresh sealed
materialization passes.
